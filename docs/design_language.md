# Design language

DataMind presents each answer with its receipt: the finding, how it was
computed, the query, returned rows, assumptions, and status. The interface is
an analyst's workbook rather than a generic chat UI.

The Streamlit theme uses the paper/surface/ink/teal tokens from
`DataMind_Tech_Stack_and_Design_Language.md`. Answers use a serif treatment,
while controls and metadata use system sans-serif. SQL and query IDs remain
monospaced. Status always includes a word, not only a color.
